# PEREHVAT DUO — Render Free (тест на 2 телефонах)

## Что внутри
Полный Python/FastAPI-сервер версии 7.7 с AR внутри истории и саундтреком 7.6. Тяжёлые PNG-атласы сжаты в WebP с прежними размерами, музыка и декорации скачиваются по запросу. Приложение запускается одним Dockerfile. `PAYMENT_MODE=demo` — оплата выключена.

## Публикация за несколько шагов
1. Создайте **Private** репозиторий `perehvat-duo-test` на GitHub и загрузите в него **содержимое этой папки**, не ZIP. Убедитесь, что файлы `server.py`, `Dockerfile`, `render.yaml`, `static/` и `private/` лежат в корне репозитория. Приватный репозиторий важен: здесь находятся файлы сценариев и иллюстрации.
2. Откройте https://dashboard.render.com/ → New → Web Service → подключите GitHub → выберите репозиторий `perehvat-duo-test`.
3. Runtime: Docker; Instance Type: **Free**; имя `perehvat-duo-test`. Render сможет прочитать Dockerfile. Важнее всего не выбрать платный экземпляр. Если Render предлагает Blueprint, можно использовать `render.yaml`.
4. Дождитесь статуса `Live` в панели Render. Адрес будет `https://имя.onrender.com` (точный выдаст Render). Откройте его на обоих телефонах.
5. Создайте новую комнату и проверьте подключение второго игрока, звук, AR и переход между главами.

## Важно
- После 15 минут без входящих запросов Free-инстанс засыпает; первый заход после паузы может занимать ~1 минуту. Пока идёт игра с двумя телефонами, опрос `/api/duo/` обычно не даёт ему уснуть.
- Папка `data` и обе SQLite-базы во Free являются **временными**. При перезапуске, повторном деплое или пробуждении после сна старые комнаты/профили могут исчезнуть. Начинайте проверку с новой комнаты.
- Не включайте реальные платежи в тестовом общедоступном сервисе.
- Если мобильный браузер показывает старую графику, откройте ссылку в режиме инкогнито или удалите сохранённые данные сайта.
- Для последующих коммерческих запусков понадобится постоянная БД и защита доступа к контенту.

## Техническая проверка локально
`pip install -r requirements.txt`
`uvicorn server:app --host 127.0.0.1 --port 8000`

Публичная ссылка через Render работает независимо от вашего ПК и не требует Cloudflare/Pinggy/Dev Tunnel.
